# No bounty reports here

This directory takes **no new files.**

Bounty and audit reports — the raw text, the mechanism, reproduction steps, reporter details
and side findings — live only in the project's private repository. This repository is public:
anything written here is published, and a branch becomes public the moment it is pushed.

Here, refer to a finding by its **tracking ID** and describe the **invariant** the fix
establishes, never the attack. That applies to commit messages, KAT names, code comments,
PR text and this directory alike.

Why this file exists: on 2026-09-06 a complete report was written here (by a triage
procedure that has since been corrected), including a side finding that was then never acted
on for a month. The existing file is left as it was; whether to remove it is a disclosure
decision, and removing it from this branch would not remove it from history.
